⚠️ Gestion du compte

Contrairement aux autres comptes SINE.SHOP, un compte affilié masqué temporairement et non réactivé dans les 30 jours est automatiquement supprimé, sans passer par un examen administrateur (les autres rôles restent en attente d'une décision humaine).

Un même compte peut aussi opérer comme vendeur et/ou livreur, sans créer de second compte. Jamais de bascule possible vers un espace administrateur.

📖 Comment ça marche ?

1️⃣ Générer un code promo

Créez vos codes promo uniques. Vous pouvez les générer automatiquement ou les personnaliser.

2️⃣ Partager vos codes

Partagez vos codes avec vos amis, famille ou sur vos réseaux sociaux. Chaque inscription valide vous rapporte une commission.

3️⃣ Gagner des commissions

Pour chaque utilisateur qui s'inscrit avec votre code et réalise un achat, vous gagnez une commission.
